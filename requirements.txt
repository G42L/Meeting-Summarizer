# GPU/VRAM stats for the System monitor panel — optional, NVIDIA only.
# sysmon.py degrades gracefully (GPU just won't show live NVIDIA stats) if
# this isn't installed or there's no NVIDIA driver; AMD/Intel GPUs on Linux
# are still detected without this, via sysfs. See sysmon.py's docstring.
nvidia-ml-py>=12.0

# Speaker diarization ("Label speakers" checkbox) — optional and heavy:
# pulls in torch/torchaudio, and needs a free Hugging Face account with an
# access token that has accepted the gated "pyannote/speaker-diarization-3.1"
# model's terms at huggingface.co before it will load. diarization.py
# degrades gracefully (is_available() reports it cleanly, jobs fall back to
# the plain transcript) if this isn't installed or the token/model access
# isn't set up. CPU-capable but much faster with a CUDA GPU -- torch
# auto-detects and uses one if available, nothing extra to configure here.
# Also faster-whisper-only: whisper-cli's plain-text output has no segment
# timestamps to align speaker turns against.
pyannote.audio>=3.1

# Text-to-speech (prototype) — optional and light: pure Python + onnxruntime,
# no torch. Voice models (~60 MiB each) download once on first use via
# `python -m piper.download_voices <voice>`, cached locally afterward.
# tts_engine.py degrades gracefully (is_available() reports it cleanly) if
# this isn't installed.
piper-tts>=1.3

# Platform-specific system-audio (Teams/loopback) capture:
#
# Windows — install sounddevice too (bundles PortAudio automatically,
#   nothing extra to apt/brew install):
#     pip install sounddevice
#   Only needed if you actually add a "(loopback)" source; the app runs
#   fine without it otherwise. miniaudio's Python binding doesn't expose
#   WASAPI loopback, which is why this one path still uses sounddevice.
#
# macOS — install BlackHole (free virtual audio driver, not a pip
#   package): https://existential.audio/blackhole/
#   Route Teams's output (or a macOS Multi-Output Device combining
#   BlackHole + your speakers) to it -- it then just appears as a normal
#   input device, captured by miniaudio like a microphone.
#
# Linux — nothing extra needed. Every PulseAudio/PipeWire sink already
#   has a ".monitor" source you can select directly in the Add Source
#   picker, and miniaudio talks to it with zero system packages.
